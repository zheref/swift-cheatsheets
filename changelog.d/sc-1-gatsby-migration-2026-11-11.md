### Changed

- **The site is now Gatsby 5 + TypeScript + Chakra UI 3, built from a language catalog kept as data (zheref/swift-cheatsheets#1).** The 29 Swift sheets (289 cards, 17 diagrams) moved from Python renderer calls to validated YAML under `content/languages/swift/`, with stable concept IDs, scope, applicability, expected results and sources in the schema; a new language is a new content folder rendered by the same page. Every anchor, card, code block and diagram is proven identical to the pre-migration page by digest, and search returns the same results. The committed `index.html` is now the offline artifact — one self-contained, server-rendered and hydrated file that still works from disk with no network. Python is no longer needed to build or serve: `npm run build`, `npm run verify`, `npm test`, and `serve.command` / `serve-https.command` run on Node.
