### Added

- **TypeScript, Kotlin and C# catalogs (zheref/swift-cheatsheets#3).** Three new catalogs, kept as data under `content/languages/` and published at `/typescript/`, `/kotlin/` and `/csharp/` (offline: `offline/<id>.html`). Each keeps shared concepts, language topics and platform material — Node.js and the browser; the JVM and Android; .NET — in separate sidebar groups, and reuses the Swift concept ids where a topic is truly equivalent, so the language selector keeps the reader on the same concept. Every example carries its setup, platform/runtime/version applicability, sources, the result it produces and a validation status (`ran`, `compiled` or `excerpt`, with the toolchain and date it was proved on, or the application host it needs). A coverage matrix at the end of each catalog gives every Swift topic a disposition — equivalent, partial or no counterpart, with the reason.
- **`npm run examples`** compiles and runs the catalogs' examples with the real compilers and runtimes and checks each one's output against the documented result; a missing toolchain is reported as skipped, never as a pass. CI runs the TypeScript and C# examples on every pull request; the Kotlin ones run where `kotlinc` is installed.
- **Example metadata in the content model:** `prerequisites` and `validation` on `code` and `compare` cards, and `requireExampleMetadata` on a language, which makes the loader refuse an example that omits any of it.
