### Changed

- **The repository now pins nen 0.30.0.** `nen/contract.json` moves its `dependency` block from v0.21.0 to v0.30.0, the build Hatsu itself pins: nen 0.30's compatibility floor refuses any minimum under 0.30, so `nen shu tools` read the pin as `WRONG` on every host. The bootstrap script and the darwin-arm64 binary at v0.30.0 were checked against Hatsu's recorded digests. The pull-request readiness workflow reads the pin from the trusted base, so it moves to 0.30 for the pull requests after this one lands; nen 0.30's readiness output carries the same six conjuncts the workflow's reader expects.

### Added

- **Four focused test lanes beside `site`.** `nen/contract.json` declares `site-ui` (src/bankai, src/ui), `site-content` (src/content, content/), `site-adapters` (src/adapters, src/pages, gatsby-*) and `site-scripts` (scripts/), each a fixed `vitest run` over the test files that import that area, so a local checkpoint runs the tests a change can move rather than the whole suite. None measures coverage: the whole suite and its coverage stay the `site` lane's.
