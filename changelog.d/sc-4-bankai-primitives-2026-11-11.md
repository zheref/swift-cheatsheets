### Added

- **Reusable UI primitives for Bankai, defined and proven here first (zheref/swift-cheatsheets#4).** `src/bankai/` holds the reference's layout shell, topic rail, search field, disclosure selector, code block with opt-in copy feedback, theme toggle and colour-scheme hook, on a token module (colour, type, spacing, radius, size, layer and overlay roles) that zheref/swift-cheatsheets#5 builds on. They know no language, no content model and no router. The page now composes them, and its rendered markup and styles are byte-identical to before. A proof suite renders them for the TypeScript and Kotlin fixtures under a theme that is not the product's, covering static rendering, hydration, keyboard use and both schemes. [docs/BANKAI-PRIMITIVES.md](docs/BANKAI-PRIMITIVES.md) records the inventory of the existing Bankai owner (zheref/bankai-site), an ownership decision for every candidate, and the extraction proposal: destination, public contracts, dependency direction, semver, migration steps and the scope of the upstream follow-up. Nothing is published.
