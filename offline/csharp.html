Dictionary and HashSet

`GetValueOrDefault` reads a missing key as the default; `UnionWith` changes the set in place.

var counts = new Dictionary<string, int>();
foreach (var word in "the cat and the hat".Split(' '))
{
    counts[word] = counts.GetValueOrDefault(word) + 1;
}
Console.WriteLine(string.Join(", ", counts.OrderBy(kv => kv.Key, StringComparer.Ordinal).Select(kv => $"{kv.Key}={kv.Value}")));
Console.WriteLine($"{counts["the"]} {counts.ContainsKey("dog")} {counts.TryGetValue("cat", out var cat)} {cat}");

var set = new HashSet<int> { 1, 2, 3 };

A read-only interface is a view; immutable collections return new ones; frozen ones trade build time for fast reads.

Pitfalls

Where C# differs from Swift's value-type collections.

  • Modifying a List or Dictionary inside its own foreach throws InvalidOperationException.
  • list.RemoveAt(0) in a loop is O(n²) — use Queue<T>.
  • Relying on Dictionary or HashSet enumeration order: it is an implementation detail.
  • Expose IReadOnlyList<T> / IReadOnlyDictionary from APIs and keep the mutable type private.
  • Collections are reference types even when they hold structs: var b = a aliases the list.

Deferred execution

A query is a recipe, not a result — it runs each time it is enumerated, against the source as it is then.

source.Add(4);
Console.WriteLine(string.Join(",", evens));    // runs now, and sees 4

var snapshot = evens.ToList();                  // materialize once

Rules

Where LINQ costs more than it looks.

  • Enumerating the same query twice runs it twice — including any database or network call behind an IQueryable.
  • Count() > 0 walks the sequence; Any() stops at the first element.
  • Materialize (ToList, ToArray) at the boundary where you want a snapshot.
  • Lambdas in hot loops allocate; for tight numeric code a for loop over a Span<T> is faster.

Sequential vs concurrent

A task starts when it is created; `await` only waits. Start both, then await both.

using System.Diagnostics;

static async Task<string> Load(string name)
{
    await Task.Delay(100);                         // frees the thread while waiting
    return name;
}

var clock = Stopwatch.StartNew();
var user = await Load("user");
var posts = await Load("posts");
var sequential = clock.ElapsedMilliseconds;

clock.Restart();
var both = await Task.WhenAll(Load("user"), Load("posts"));
var concurrent = clock.ElapsedMilliseconds;
Console.WriteLine($"{user} {posts} | {string.Join(" ", both)}");
// About 200 ms against about 100 ms; compared, not printed, so a busy machine cannot change the output
Console.WriteLine($"concurrent took well under the sequential time: {concurrent < sequential * 3 / 4}");

WhenAll and its exceptions

`await` rethrows the first failure only; the task's `Exception` holds all of them.

static async Task<int> Work(int n)
{
    await Task.Delay(10 * n);
    return n == 2 ? throw new InvalidOperationException($"job {n} failed") : n;

var all = Task.WhenAll(Work(1), Work(2), Work(3));

Async streams

`IAsyncEnumerable` is the pull-based stream; `break` disposes the enumerator, so no further page is fetched.

using System.Runtime.CompilerServices;

static async IAsyncEnumerable<int[]> Pages(int total, int size, [EnumeratorCancellation] CancellationToken token = default)
{
    for (var offset = 0; offset < total; offset += size)
    {
        await Task.Delay(10, token);               // stand-in for a fetch
        yield return Enumerable.Range(offset, Math.Min(size, total - offset)).ToArray();
    }
}

var seen = 0;
await foreach (var page in Pages(7, 3))
{
    seen += page.Length;
    Console.WriteLine(string.Join(",", page));
    if (seen >= 6) break;
}

Rules

What reviewers flag first.

  • async void outside event handlers: exceptions crash the process and nobody can await it.
  • .Result / .Wait() on a UI or legacy ASP.NET context deadlocks — await all the way up.
  • Accept a CancellationToken in every async API and pass it to everything you call.
  • ConfigureAwait(false) in library code that does not need the caller's context.
  • ValueTask only for hot paths that usually complete synchronously; await it exactly once.

Two pointers

On sorted input, move the pointer that brings the sum closer. O(n), O(1) space.

static (int, int)? PairWithSum(int[] sorted, int target)
{
    int lo = 0, hi = sorted.Length - 1;
    while (lo < hi)
    {
        var sum = sorted[lo] + sorted[hi];
        if (sum == target) return (lo, hi);
        if (sum < target) lo++; else hi--;
    }
    return null;
}

Console.WriteLine($"{PairWithSum([1, 3, 4, 6, 9], 10)} {PairWithSum([1, 2], 7)?.ToString() ?? "none"}");

Sliding window

Longest substring without repeats — grow the right edge, jump the left past the last repeat. O(n).

static int LongestUnique(string s)
{
    var lastSeen = new Dictionary<char, int>();
    int start = 0, best = 0;
    for (var i = 0; i < s.Length; i++)
    {
        if (lastSeen.TryGetValue(s[i], out var prev) && prev >= start) start = prev + 1;
        lastSeen[s[i]] = i;
        best = Math.Max(best, i - start + 1);
    }
    return best;
}

Console.WriteLine($"{LongestUnique("abcabcbb")} {LongestUnique("pwwkew")}");

Heap — top k

A min-heap of size k keeps the k largest; its root is the smallest of them. O(n log k).

static int[] TopK(IEnumerable<int> xs, int k)
{
    var heap = new PriorityQueue<int, int>();
    foreach (var x in xs)
    {
        heap.Enqueue(x, x);
        if (heap.Count > k) heap.Dequeue();
    }
    return [.. heap.UnorderedItems.Select(e => e.Element).OrderDescending()];
}

Console.WriteLine(string.Join(",", TopK([5, 1, 9, 3, 7, 9, 2], 3)));

Breadth-first search on a grid

BFS finds shortest paths in unweighted graphs.

static int ShortestPath(string[] grid, (int R, int C) from, (int R, int C) to)
{
    var dist = new Dictionary<(int, int), int> { [from] = 0 };
    var queue = new Queue<(int R, int C)>([from]);
    while (queue.TryDequeue(out var cell))
    {
        var here = dist[cell];
        if (cell == to) return here;
        foreach (var (dr, dc) in new[] { (1, 0), (-1, 0), (0, 1), (0, -1) })
        {
            var next = (R: cell.R + dr, C: cell.C + dc);
            if (next.R < 0 || next.C < 0 || next.R >= grid.Length || next.C >= grid[0].Length
                || grid[next.R][next.C] == '#' || dist.ContainsKey(next)) continue;
            dist[next] = here + 1;
            queue.Enqueue(next);
        }
    }
    return -1;
}

Working a problem out loud

The habits that matter more than the language.

Design for testability — inject TimeProvider

Code that asks a `TimeProvider` for the time can be tested without sleeping.

var clock = new ManualClock(new DateTimeOffset(2026, 1, 1, 0, 0, 0, TimeSpan.Zero));
var session = new Session(clock, TimeSpan.FromMinutes(30));
Console.WriteLine(session.Expired);
clock.Advance(TimeSpan.FromMinutes(30));       // the test owns time
Console.WriteLine(session.Expired);

class Session(TimeProvider time, TimeSpan ttl)
{
    private readonly DateTimeOffset started = time.GetUtcNow();
    public bool Expired => time.GetUtcNow() - started >= ttl;
}

// FakeTimeProvider (Microsoft.Extensions.TimeProvider.Testing) does this, plus timers
class ManualClock(DateTimeOffset start) : TimeProvider
{
    private DateTimeOffset now = start;
    public override DateTimeOffset GetUtcNow() => now;
    public void Advance(TimeSpan by) => now += by;
}

An async mutex with SemaphoreSlim

var gate = new SemaphoreSlim(1, 1);

        var read = balance;
        await Task.Yield();                    // an await inside the critical section
        balance = read + amount;
    }
    finally
    {
        gate.Release();
    }
}

Rules

Without a compiler check, the design has to make races impossible.

  • Prefer immutable messages: record types with init properties, ImmutableArray<T>.
  • ConcurrentDictionary for a shared cache; GetOrAdd may run the factory more than once.

Writing atomically

Write a temporary sibling, `Flush(flushToDisk: true)`, then move it over the target in one rename.

static void WriteAtomically(string path, string text)
{
    var temp = Path.Combine(Path.GetDirectoryName(path)!, $".{Path.GetFileName(path)}.{Guid.NewGuid():N}.tmp");
    using (var stream = new FileStream(temp, FileMode.CreateNew, FileAccess.Write))
    using (var writer = new StreamWriter(stream))
    {
        writer.Write(text);
        writer.Flush();
        stream.Flush(flushToDisk: true);       // on the device before the move publishes it
    }
    File.Move(temp, path, overwrite: true);    // a rename within one volume
}

var dir = Directory.CreateTempSubdirectory("atomic-");
var settings = Path.Combine(dir.FullName, "settings.json");
WriteAtomically(settings, """{"theme":"dark"}""");
WriteAtomically(settings, """{"theme":"light"}""");
Console.WriteLine(File.ReadAllText(settings));
dir.Delete(recursive: true);

Rules that prevent data loss

.NET adds a few platform differences.

  • Dispose every stream (using / await using) — Dispose flushes; a missed one loses the tail.
  • Replace a file with a temporary sibling + move; never truncate the original first.
  • File.Replace(temp, path, backup) also keeps a backup of the old file and the target's metadata; it needs both files on the same volume.
  • Path.GetTempFileName() creates a file in the shared temp folder — do not use it as a sibling for an atomic move to another volume.
  • Paths: Path.Combine and Path.GetRelativePath, never string concatenation with \.

INotifyPropertyChanged by hand

Raise the event for the property and for anything derived from it; skip equal values.

using System.ComponentModel;
using System.Runtime.CompilerServices;

var vm = new CounterViewModel();
vm.PropertyChanged += (_, e) => Console.WriteLine($"{e.PropertyName} changed");   // what a binding listens to
vm.Increment();
vm.Count = 1;                                  // the same value: no notification
Console.WriteLine(vm.Label);

class CounterViewModel : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler? PropertyChanged;
    private int count;

    public int Count
    {
        get => count;
        set
        {
            if (count == value) return;
            count = value;
            OnPropertyChanged();
            OnPropertyChanged(nameof(Label));
        }
    }

    public string Label => $"Clicked {Count} times";
    public void Increment() => Count++;

    private void OnPropertyChanged([CallerMemberName] string? name = null) =>
        PropertyChanged?.Invoke(this, new PropertyChangedEventArgs(name));
}

Rules

Most binding bugs are one of these.

  • Raising PropertyChanged off the UI thread in WPF or WinUI — marshal to the dispatcher first.
  • Replacing an ObservableCollection instance without raising PropertyChanged for it: the bound list keeps the old one.
  • Derived properties raise their own notification when a source changes (NotifyPropertyChangedFor).
  • View models stay UI-free, so they run and are tested in a plain console or test project — as above.
