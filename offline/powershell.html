Preserve a complete path

Single quotes keep text literal. Double quotes expand variables. Use an argument array and splatting to pass several values.

function Show-InputPath {
    param([string]$Path)
    "<$Path>"
}

Show-InputPath @arguments

Restore a working directory

Push-Location and Pop-Location pair even when a cmdlet throws. A child process inherits environment variables, while ordinary PowerShell variables stay in the current session.

$before = Get-Location

try { $null = Get-Location } finally { Pop-Location }
(Get-Location).Path -eq $before.Path

Collect and release a job

Start-Job runs in a separate process. Receive-Job reads its output. On early cancellation use Stop-Job, then remove the completed job record.

$job = Start-Job { 'ready' }
try {
    $job | Wait-Job | Out-Null
    $job | Receive-Job -ErrorAction Stop
} finally {
    $job | Remove-Job -Force
}

ready
